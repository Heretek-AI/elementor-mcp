# Kadence Theme & Blocks Integration

Instructions for AI agents utilizing Kadence Blocks and Kadence theme settings.

## Kadence Block Standards
- `kadence/rowlayout`: Main grid container with custom columns, gutter, and responsive collapse.
- `kadence/advancedheading`: Heading with typography controls, badge options, and subtext.
- `kadence/infobox`: Icon/image card with title, description, and link actions.
