# SEO & Accessibility Toolkit

Analyze and optimize page accessibility and on-page SEO without external API dependencies.

## Key Abilities
- `audit-page-a11y`: Scans Elementor page structure for WCAG 2.1 compliance (contrast, headings, alts).
- `analyze-contrast`: Evaluates color pairs for AA/AAA compliance.
- `audit-page-seo`: Calculates keyword density, heading structure, and meta tags.
- `generate-schema-markup`: Emits JSON-LD structured data.
